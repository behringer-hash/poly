# Запуск бота C1 на сервере в Стокгольме: подробная инструкция

Вариант C1: порог 0,03, σ ×1, источник Bybit, покупка 5 шейров (не меньше $1 на ордер), переплата 3 цента,
удержание до конца окна. Лимиты: 10 ордеров и $30 на окно, $100 в сутки, стоп при убытке $20 за сутки,
пауза между ордерами 10 секунд.

Режимы: `dry` ничего не подписывает и не отправляет (ключ не нужен); `sign` подписывает, но не отправляет (нужен ключ);
`live` отправляет настоящие ордера и запускается только после прямого «да» владельца счёта.

## 0. Что нужно
- доступ к серверу (Lightsail → Instances → ваш сервер → Connect using SSH, пользователь `ubuntu`);
- папка с ботом (в ней лежит `bot.py`), та, из которой вы уже запускали бота;
- в кошельке Polymarket не больше суммы, которую готовы потерять в тесте (лимит бота $100 в сутки).

## 1. Найти папку бота
```bash
ls ~
find ~ -maxdepth 3 -name bot.py 2>/dev/null
```
Дальше `cd` в папку, где лежит `bot.py` (например, `cd ~/btc5m_lab`). Проверка, что бот умеет нужное:
```bash
python3 bot.py --help | grep -E "variants|live|mode|single-clob"
python3 -c "import py_clob_client_v2; print('библиотека Polymarket есть')"
```
Если библиотеки нет: `pip3 install py_clob_client_v2 --break-system-packages`.

## 2. Файл настроек
```bash
nano live_config_c1.json
```
Вставьте содержимое `live_config_c1.example.json` из репозитория (там все лимиты), впишите `funder` — адрес вашего
кошелька Polymarket. Сохранить: Ctrl+O, Enter; выйти: Ctrl+X. Приватный ключ в файл не писать.

## 3. Режим dry (1–2 часа, ключ не нужен)
```bash
tmux kill-session -t c1 2>/dev/null   # если сеанс c1 уже есть (ошибка «duplicate session») - удалить старый
tmux new -s c1                       # сеанс, который живёт после закрытия окна
python3 bot.py --live live_config_c1.json --mode dry --no-chart --clip 5 --single-clob \
    --variants c1:0.03:bybit:1 --latencies 200,300 --show c1@200 --slip-ticks 3 2>&1 | tee -a ~/c1_dry.log
```
Что должно быть: бот подключается к Polymarket и Bybit, раз в 10 секунд печатает статус; при сигнале строки `[LIVE ...]`
— «отправил бы» или «пропуск: причина» (лимит окна, слишком часто и т.п.). Отключиться, оставив бота работать:
Ctrl+B, затем D. Вернуться: `tmux attach -t c1`. Остановить: Ctrl+C.
Контроль нагрузки: `free -m` (память), в статусе бота `loop p99` (должно быть единицы миллисекунд).

## 4. Режим sign (1–2 часа, нужен ключ)
Остановите dry (Ctrl+C) и запустите в том же окне:
```bash
read -s PM_PRIVATE_KEY && export PM_PRIVATE_KEY      # вставьте ключ вслепую, Enter; он не попадёт в историю
python3 bot.py --live live_config_c1.json --mode sign --no-chart --clip 5 --single-clob \
    --variants c1:0.03:bybit:1 --latencies 200,300 --show c1@200 --slip-ticks 3 2>&1 | tee -a ~/c1_sign.log
```
Проверяется: баланс кошелька, верный `signature_type` (бот перебирает варианты и подскажет), подпись ордеров,
размер ордера ≥ $1. Ордера не отправляются. После остановки: `unset PM_PRIVATE_KEY`.

## 5. Режим live — только после моего «да» и вашего подтверждения лимитов
Команда как в п. 4, но `--mode live`; бот попросит ввести «ДА». Папку для данных можно задать `--data-dir bot_data_c1`.
- Аварийная остановка: `touch STOP` в папке бота (новые ордера прекращаются), потом Ctrl+C.
- Выигрыш нужно забирать вручную (Claim) в интерфейсе Polymarket.
- Ордера, результаты и сверка с бумагой пишутся в `bot_data_c1/`.

## 6. Сверка с реплеем (через 12–24 часа live)
`python3 live_vs_paper.py bot_data_c1 --variant c1` и мой отчёт по записи сервера.
Ожидание по реплею: доля исполнений ≈ 15–25%, прибыль на сигнал ≈ +1,5…+3 ц на шейр.
Остановка и разбор: исполнений < 8%, прибыль около нуля или дневной убыток > $10 два дня подряд.

## Если что-то не так
| Симптом | Что делать |
|---|---|
| «БУМАГА: ПРОМАХ» при том, что лучший ask ниже лимита живого ордера | бумажный счёт без ключа `--slip-ticks 3` не платит переплату и считает промахом то, что живой ордер с лимитом +3 ц купил бы; добавьте `--slip-ticks 3` (нужна версия bot.py с этим ключом) |
| `вариант anc_3c_by не найден` | забыт ключ `--show c1@200` (по умолчанию бот показывает вариант anc_3c_by) |
| `duplicate session: c1` | сеанс уже существует: `tmux attach -t c1` или `tmux kill-session -t c1` и заново |
| `ModuleNotFoundError` | `pip3 install <модуль> --break-system-packages` |
| `sign` пишет про другой signature_type | поправьте значение в `live_config_c1.json` по подсказке |
| `loop p99` в сотни мс | остановите запись данных: `sudo systemctl stop lab-collector` (потом `start`) |
| Нет сигналов в dry | это нормально, их ~1–2 в минуту днём и реже ночью; ждите |
| Ошибки сети/разрыв | бот переподключается сам; если нет — Ctrl+C и запуск заново |
